# @deepseek-ai/dsh-file-attachment

[English](README.md) | 中文

持久 UTF-8 文件附件 seam。`ctx.fileAttachments` 校验并原子提交不可变文本文件字节，然后返回可序列化的 `TextFileAttachmentRef`；消费方绝不会在会话事件中持久保存宿主路径、浏览器对象 URL、提供方 URL 或 base64。

`validateTextFile` 运行相同的准入策略，但不执行持久化。批量写入方会先校验每个成员，避免被拒绝的文件发布部分消息。`saveTextFile` 在发布所属会话事件前提交已接收文件。`readTextFile` 校验已存字节、引用元数据和 UTF-8 解码；调用方可以取消读取。

## 模型体验

`FileBlock` 是角色无关的模型输入。宿主仅在持久化准入成功后写入它；提供方在构建请求前即时解析其引用。标准 pi-ai 适配器会渲染带明确边界的文件标题、媒体类型和已校验 UTF-8 文本。模型代码绝不会收到宿主路径或目录授权。

#### KV 缓存影响

文件块属于普通文本上下文，其影响遵循提供方对文本上下文缓存的常规行为。

## 已知限制与待完成工作

- **仅 UTF-8 文本** — 二进制文档需要格式专属的提取和提供方表示。
- **无模型文件系统访问** — 选中的目录只会贡献明确选取的文件字节，不会成为工具或路径能力。
